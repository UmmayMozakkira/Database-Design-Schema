# Database Design & Schema Collection

This repository showcases my projects in database modeling and architecture. As an aspiring **Data Analyst**, I focus on designing schemas that ensure data integrity and optimized analytical reporting.

## 🚀 Projects

### 1. Bus Ticket Booking System (Star Schema)
Designed to manage high-frequency transactions with a focus on analytical efficiency.
- **Key Features:** Centralized booking fact table, seat management, and payment tracking.
- **Schema Type:** Star Schema
- **Interactive View:** [View on DrawSQL](https://drawsql.app/teams/mst-ummay/diagrams/bus-ticket-booking-system)

### 2. Library Management System (Snowflake Schema)
Focused on deep normalization and managing complex relationships between multiple entities.
- **Key Features:** Member transactions, book reservations, and fine calculation logic.
- **Schema Type:** Snowflake Schema
- **Interactive View:** [View on DrawSQL](https://drawsql.app/teams/mst-ummay/diagrams/library-management-system-lms))

## 🛠️ Tools Used
- **DrawSQL:** For ER diagram creation and visual modeling.

## 📈 Learning Goals
- Mastering Primary & Foreign Key relationships.
- Understanding the difference between Star and Snowflake schemas for Data Warehousing.
- Bridging the gap between raw business logic and structured data.
